## 1. Overview & Vision

**Social Studio** is an all-in-one operational cockpit and AI-assisted content engine built for social media managers, marketing agencies, and digital creators. It streamlines multi-brand publishing, psychological viral hook engineering, Instagram 9-grid previews, and frictionless client review workflows via WhatsApp.

---

## 2. Key Features

1. **Multi-Brand Workspace Management:** Manage distinct client brand voices, aesthetic color palettes, and audience demographics from a single unified view.
2. **Viral Hook & Script Studio:** 50+ psychological hook formulas (curiosity gaps, contrarian perspectives, mistake-correction, step-by-step breakdowns) with structured Reels/Carousel templates.
3. **Instagram 9-Grid Simulator:** Real-time visual grid planning to verify aesthetic coherence, color rhythm, and typography flow before publishing.
4. **Strategic Content Calendar:** Automated balance across Core Pillars (40% Value, 30% Social Proof, 20% Behind-the-Scenes, 10% Conversion/Offer).
5. **Client Review & WhatsApp Approval:** One-click WhatsApp review card generation allowing clients to inspect, approve, or request revisions without signing into an agency portal.
6. **100% Local Data Custody:** Client content and drafts stay locally in your browser and on local disk storage.

---

## 3. Tech Stack

- **Frontend:** Vanilla JavaScript (ES2024), Semantic HTML5, Modular CSS
- **Testing:** Native Node.js Test Runner (`node --test`) with 72 automated unit tests
- **Deployment:** Vercel Production (`https://social-studio-app.vercel.app`)
- **Telemetry:** Firebase Cloud Firestore REST integration (`hopem-software-cloud`)

## 4. Getting Started

cd social-studio

npm test

# Run local preview
